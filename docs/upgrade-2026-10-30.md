# Public landing page — 2026-10-30

The front door at `/` used to redirect every visitor to `/login`. That kept the
product invisible to search engines, link previews and anyone evaluating Tflash
before creating an account. This change makes `/` a real public page without
weakening any private route.

## What changed

- **One route, two states.** `app/page.tsx` resolves the session once. Visitors
  get `<LandingPage />`; signed-in accounts get the existing chat shell with the
  already-resolved principal. `/s`, `/s/[sessionId]`, `/api/*`, `/auth/*` and
  `/eve/*` are untouched and still require an owner.
- **Bilingual landing page.** `components/marketing/landing-page.tsx` carries the
  same EN/SO switch as `/login` (shared `tflash:language` key) and covers the
  product loop: choose a model, connect approval-gated tools, research with
  source receipts, download finished documents, and use voice where the browser
  supports it.
- **Honest copy.** The security section states the AES-GCM key handling, the
  fresh-approval rule for shell/MCP calls, and the ownership checks on Supabase
  history. It does not claim perfect security, an audit ledger or a hard billing
  cap; those limits stay in the README.
- **Sign-up deep link.** `/login?mode=signup` opens the create-account tab
  directly. `/login` still opens sign-in, and signed-in visitors still redirect
  to `/`.
- **Sharing and discovery.** `app/opengraph-image.tsx` generates a 1200×630 card
  from the same palette. `app/sitemap.ts` lists only `/` and `/login`, and only
  when `APP_URL` is set (an empty sitemap beats a guessed domain). `robots.txt`
  now allows the public surface and disallows the private path prefixes.

## Design notes

The page reuses the sign-in screen's fixed palette — warm paper `#fdfcfb`,
charcoal `#201e1b`, flash amber `#f3bd56` — and the existing DM Serif Display,
DM Sans and DM Mono faces. It is deliberately light in both themes, like
`/login`, because it is the brand's front door rather than the workspace. The
hero includes a still-life of a real turn, including the approval card, so the
first screen shows the product's gate rather than hiding it.

Accessibility:

- `main#main-content` keeps the global skip link working; the nav, disclosure
  widgets (`<details>`) and language switch use native semantics.
- Focus rings use the amber ring token on both the dark hero and the paper
  sections. Motion is limited to small transforms and disabled by the global
  `prefers-reduced-motion` rule.
- The decorative orbit and the product preview are hidden from assistive tech;
  all marketing copy is real text.

## Verification

Run locally with Node 24:

```bash
corepack pnpm typecheck
corepack pnpm test
corepack pnpm build
```

The build lists `/` as dynamic, and `/opengraph-image`, `/robots.txt` and
`/sitemap.xml` as static. A live screenshot check should still be done on a
deployment: this repository's CI proves compilation, route definitions and the
unit-level policy tests, not browser rendering or a production `APP_URL`.

## Boundaries

- Analytics, cookie banners and tracking scripts were not added.
- No claim of live provider, Supabase, OAuth or sandbox connectivity is made by
  this page.
- The landing page does not expose settings, models or connection controls; it
  links to `/login` and the public README only.
